# Native FM1 screen workflow

This describes the physical-device screen path generated by the ordered native source-staging scripts. It is separate from the browser workshop and from the root host bring-up app.

## HOME — four-patch Instrument

The device boots to the four-patch Instrument page. The four tiles show patch name, active/muted state, algorithm, level and selection.

- SELECT encoder: choose one of the four patch slots.
- PRESETS encoder: choose one of the 32 named Instruments in the four-bank library.
- ALGORITHM encoder: change the selected patch algorithm.
- KNOB 1–4: set the four patch levels.
- SEL button: toggle the selected patch active/muted.
- SAVE: store the complete four-patch Instrument as one bank transaction.
- EDIT or SCL: open the focused patch editor.
- GLO: open the performance macro page.
- SEQ: open the two-lane sequencer.
- FX: open the upstream effects page.

Unsaved Instrument changes block Instrument switching until saved. Existing project slots and unrelated bank entries are preserved by the versioned storage adapter.

## PATCH — focused operator editor

The focused editor works on the selected Instrument patch, not the current project track.

- SELECT: choose OP1–OP6.
- PRESETS: choose one of the four patches.
- ALGORITHM: change the DX7 algorithm; carrier/modulator roles and directed topology are derived from the routing table.
- SCL: cycle ENVELOPE, OSCILLATOR and GLOBAL groups.
- ENV: switch the envelope view between RATE and LEVEL.
- LFO on OSCILLATOR: toggle the selected operator between ratio and fixed-frequency mode.
- KNOB 1–4: edit the four values displayed in the active group.
- SAVE: store the Instrument.
- HOME or EDIT: return to HOME.
- GLO: open the macro page and return to this editor with GLO.

The current topology view identifies carrier/modulator roles, depth and directed routing text. It is not yet a node-and-connector graph; undo/compare and audition workflow remain open work.

## MACROS — four role-based performance controls

GLO opens the macro page from HOME or PATCH. The page shows the selected patch, algorithm number, current carrier/modulator roles, all four macro values and the neutral marker at 50.

- KNOB 1: BRIGHTNESS — topology-depth-scaled modulator output.
- KNOB 2: BODY — carrier sustain level.
- KNOB 3: MOTION — modulator envelope contour.
- KNOB 4: DIRT — bounded global feedback.
- PRESETS: choose the patch whose macros are being edited.
- SAVE: store the Instrument.
- GLO: return to the previous HOME or PATCH page; HOME returns to HOME.

The macro transforms are non-destructive: they are derived from the base DX7 voice and stored as macro values in the Instrument metadata. Live changes are synchronized to the audio engine.

## FX — upstream performance effects

FX continues to use the official M-VAVE effects page and engine API rather than inventing a parallel DSP path. The upstream page exposes track sends, shared effects and delay/tap controls. Its own page selector and encoder mappings remain authoritative.

## SEQ — two-lane sequencer

SEQ opens two fixed 64-step lanes, with shared tempo/swing and native step fields. SELECT chooses the step, PRESETS selects the lane, KNOB 1–4 edit on/off, pitch, velocity and gate, and PLAY toggles transport. Leaving the page stops transport and restores the project's original eight track roles.

## Validation boundary

A passing host/simulator test does not prove device audio, control feel, screen readability, storage recovery or hardware timing. The Windows JieLi device workflow must compile and package within the official FM1 layout before the artifact can be considered flashable. Actual FM1 hardware validation is still required.
