# Analog-like and modern DX7 reference sets

These are useful places to audition or benchmark the missing sounds. Rights and compatibility are kept separate from sound-design relevance.

| Set | Useful palette | FM1-Lab handling |
|---|---|---|
| [FM-1 banks by mene311](https://github.com/mene311/fm1-banks) / [audio gallery](https://mene311.github.io/fm1-banks/) | 26 themed banks: synthwave pads/bass, acid-techno, leads, ambient, industrial, sci-fi, experimental | Reference-only. MIT covers the tooling; patch data remains with original authors. Do not copy bank data without rights clearance. |
| [FM Depths by Nick Klimenko](https://lfo.store/shop/software-synths/arturia-dx7-v/fm-depths-soundset-32-presets/) | 32 six-operator DX7-compatible voices: silky strings, evolving drones, smooth pads, analog-like basses, solo leads, moving sequences | Commercial. Strong candidate to audition/purchase if we want modern warm FM voices; do not redistribute. |
| [Flywheel: DX7 by SoundEngine](https://soundengine.com/product/flywheel-dx7/) | 64 DX7 voices emphasizing Prophet/Oberheim-like analog emulations plus FM edge, basses, pads, leads and gritty tones | Commercial. Particularly relevant to the analog-like / cleaner techno / aggressive FM gap; do not redistribute. |
| [Solyaris Mesmerism](https://solyaris.altervista.org/dx7.html) | Original DX7II soundscapes: analogia, strings, bass, brass, slow pads, ambient and experimental voices | Only the free Bank 01 is exported as standard DX7 SysEx. The rest are DX7II All Data banks and are not directly compatible with the FM1's DX7 voice format; conversion is required. Full collection is paid. |

## What this means for our own library

Our CC0 archive already contains 384 name-hint analog-emulation candidates, including voices named for Moog, Prophet and Oberheim styles. These are promising starting points, not proof of analog character. We have used a few diverse groups in the draft 128-voice bank and increased lead/pad representation.

The modern external collections are useful listening references. Their patch data is not being copied into our repository. If we later acquire a commercial set, we can use it on the instrument for personal auditioning, but only add patch bytes to the source-of-truth archive if its license expressly permits redistribution.
