# Analog-like FM

Warm, rounded, subtractive-like FM voices: Prophet/Oberheim/Moog-inspired timbres, detuned movement, smooth harmonic transitions and filter-like envelopes. The current archive includes 384 imported CC0 DX7 voices from Analog and MOOG source banks. These are provisional family placements, not a claim that every voice sounds convincingly analog. Audition before final tagging and FM1 instrument selection.
