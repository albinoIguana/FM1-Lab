# Sound-family taxonomy

Folders classify **audible patch type**, not source collection, synth model, or author.

| Folder | Use for |
|---|---|
| `bass/` | Sub, mono bass, growl, FM bass, plucked bass |
| `leads/` | Expressive, mono/poly leads, bright and shimmering leads |
| `pads-strings/` | Sustained pads, strings, ensembles, evolving beds |
| `analog-emulations/` | Warm subtractive-like, Prophet/Oberheim/Moog-like FM voices |
| `keys-electric-piano/` | EP, piano-like, organ, clav, keyboard voices |
| `plucks-mallets/` | Plucked, struck, mallet, short-decay melodic voices |
| `brass-winds/` | Brass, reed, flute, breathy and formant-like voices |
| `bells-metallic/` | Bells, chimes, glass, metallic resonances |
| `sequences-motion/` | Animated rhythmic tones, arpeggio-friendly motion |
| `textures-drones-fx/` | Drones, noise, cinematic, sci-fi and experimental effects |
| `vocal-choir/` | Choir, voice, formant and vocal ensemble sounds |
| `percussion-fm/` | Tuned FM drum voices and acoustic-style FM percussion |
| `percussion-synth/` | Electronic drums, Simmons-style hits, claps and synthetic percussion |
| `needs-audition/` | Unclassified imports awaiting listening and metadata review |

A patch may have multiple secondary tags, but only one primary folder. Use tags for cross-cutting traits such as `shimmer`, `warm`, `detuned`, `aggressive`, `clean`, `wide`, `evolving`, `mono`, `poly`, `velocity-sensitive`, `short-decay` and `filter-like`.

## Curation rubric

Each candidate is auditioned at low, middle and high registers; with short and sustained notes; and at multiple velocities where applicable. Record:
- tonal identity and useful register;
- attack, decay and sustain behavior;
- harmonic character (warm, bright, hollow, metallic, noisy);
- motion (static, evolving, rhythmic, modulated);
- playability (lead, chord, bass, percussive, FX);
- loudness/headroom and note-off behavior;
- similarity to existing archive patches.

Do not infer "analog-like" from a name alone. Confirm by ear: smooth harmonic spectrum, rounded attack, modest/controlled sidebands, detune/beating, filter-like envelope motion, and no brittle metallic edge unless intended.
